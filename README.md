# Final Unity Project 

## What I Actually Did
This game started out as a simple rolling ball thing and ended up being way more chaotic (in a good way). The player shoots to move, each shot shrinks them, and if they get too small, it's game over. You can pick up items to grow, avoid fire traps that shrink you, and hit speed pads for a boost.

I added lap tracking, a leaderboard, and a CSV logger that saves data like player name, lap times, and size info. That file can be downloaded after the game ends.

I dealt with a ton of bugs: broken prefabs, UI panels acting weird, and random size explosions after collecting pickups. But the biggest win was getting the recoil to feel smooth and responsive and made the gameplay fun. Because of all this, I also learned how to use Git to roll back versions when things broke (which was often).

##  Features I Built
- Shooting movement (with scaling) and recoil
- Pickups that grow the player
- Fire traps that shrink the player
- Speed pads that boost you forward
- Lap counter and dynamic layout switching
- Destructible wall obstacle
- Tilting platform
- Spinning wheel trap
- Wind tunnel zone
- Game Over when too small
- Leaderboard with player names
- Full UI system (Start, HUD, Game Over, Leaderboard)
- Visual effects (confetti, explosions)
- Sound FX for pickups, shooting, lap wins, and background music
- CSV logger that records gameplay data and lets you download it
- Camera follow with a dynamic life bar based on player scale
  
## What I Learned
- Rigidbody physics, shooting mechanics, and scaling
- UI panels and switching scenes with logic
- Git 
- How to make a complete little system that kind of works
